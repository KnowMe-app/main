# Анкети з групового чату Telegram

Дві фази:

1. **Читання** — застосунок Claude на компʼютері з керуванням компʼютером.
   Claude гортає чат у Telegram Desktop, оцінює кожне повідомлення й складає
   файл `telegram_intake.json`.
2. **Запис** — хмарна сесія Claude Code на репозиторії `knowme-app/main`.
   Шукає людей за ніком, показує таблицю на перевірку, заводить і доповнює
   картки.

## Фаза 1. Читання

### Підготовка

1. Застосунок Claude на компʼютері → нова розмова → увімкнути керування
   компʼютером, дати доступ до Telegram.
2. Telegram Desktop на весь екран, світла тема, відкритий потрібний чат.
3. Сповіщення й заставку екрана вимкнути, компʼютер на час роботи не чіпати.
4. Перевірка: «Зроби знімок екрана й перепиши три останні повідомлення з
   відкритого чату». Текст прочитано — вставляти промпт нижче.

### Промпт

Підставте назву чату й дату початку:

```
Ти читаєш груповий чат Telegram «<НАЗВА ЧАТУ>» у Telegram Desktop з
<ДД.ММ.РРРР> до найновішого повідомлення. Текст бери лише зі знімків екрана.
У чаті нічого не пиши, реакцій не став, посилань не відкривай.

1. Перейди до дати початку (пошук у чаті → календар).

2. Читай екран зверху вниз і кожному повідомленню признач одну або кілька
   категорій:

   Намір і участь
   P1 — хоче стати донором ооцитів
   P2 — хоче стати сурогатною мамою
   P3 — хоче в програму, тип не назвала
   P4 — шукає агенцію, клініку чи програму; питає умови, оплату, вимоги
   P5 — зараз у програмі (етап: обстеження, стимуляція, перенос, вагітність)
   P6 — уже була в програмі: скільки разів, коли, чим закінчилось
   P7 — відмовилась від участі або не підійшла (причина)

   Анкетні дані — лише про саму авторку
   D1 — вік, дата чи рік народження
   D2 — країна, область, місто, готовність переїхати
   D3 — пологи: кількість, дата останніх, кесарів (скільки), діти
   D4 — зріст, вага, група крові й резус
   D5 — здоровʼя: хронічні хвороби, операції, алергії, куріння, алкоголь
   D6 — сімейний стан
   D7 — освіта, робота
   D8 — контакти: телефон, інший нік, інстаграм

   Контекст
   X1 — згадує конкретну агенцію чи клініку (назва + відгук або досвід)
   X2 — рекомендує іншу людину або каже про когось, хто хоче в програму
        (дані такої людини не записуй авторці — заведи окремий запис, якщо
        є імʼя чи нік)
   X3 — питання до авторки від інших про програму, на яке вона відповіла
        (читай відповідь як її дані)

   Пропуск
   S  — світська розмова, побут, жарти, стікери, фото без підпису

3. Для кожної нової людини з будь-якою категорією, крім S, один раз клацни
   на імʼя чи аватар, перепиши @username і телефон (якщо видно), закрий
   профіль.

4. Відносні дати переводь у точні від дати повідомлення: «народила 3 міс
   тому» у повідомленні від 10.06.2026 → "2026-03", approx: true.

5. Гортай вниз на висоту екрана так, щоб останнє прочитане повідомлення
   лишалось угорі. Повідомлень не пропускай.

6. Кожні 20 екранів дописуй ~/Documents/telegram_intake.json і онови
   "resumeFrom" — дата й час останнього прочитаного повідомлення. Після
   перерви продовжуй з нього.

7. Наприкінці: скільки людей, скільки з категоріями P, скільки лише з D,
   які повідомлення не прочитались.

Формат файлу:
{
  "chat": "<НАЗВА ЧАТУ>",
  "resumeFrom": "2026-06-10T14:32",
  "people": [
    {
      "displayName": "Оля Ковальчук",
      "username": "olya_k",
      "phone": "",
      "intent": "ed",
      "programStatus": "",
      "facts": {
        "birth": "1996",
        "country": "Україна", "region": "Київська", "city": "Бровари",
        "ownKids": "2", "lastDelivery": "2026-03", "csection": "2",
        "height": "", "weight": "", "blood": "",
        "maritalStatus": "", "smoking": "", "chronicDiseases": "",
        "surgeries": "", "allergy": "",
        "education": "", "profession": "",
        "experience": "", "surrogacyExperience": "",
        "instagram": ""
      },
      "agencies": [ { "name": "", "opinion": "" } ],
      "evidence": [
        { "date": "2026-06-10", "categories": ["D3"], "field": "csection",
          "quote": "в мене два кесарева", "approx": false }
      ]
    }
  ]
}

intent: "ed" — P1, "sm" — P2, "unknown" — P3/P4 без типу, null — наміру
немає. programStatus — коротко з P5/P6/P7. facts — лише сказане авторкою про
себе, порожнє — "". Різні значення в різний час — бери новіше, обидві
цитати лиши в evidence.
```

## Фаза 2. Запис у KnowMe

Хмарна сесія Claude Code на `knowme-app/main`, прикріпити
`telegram_intake.json`, написати: «Заведи анкети з telegram_intake.json за
docs/telegram-chat-intake.md».

Кроки сесії:

1. **Нормалізація**: `birth`, `lastDelivery` → `РРРР-ММ-ДД` (рік чи місяць без
   дня — перше число); `csection` → `-` / `1` / `2`; `intent` → `userRole`
   (`ed` / `sm`); `telegram` = `username` без `@`.
2. **Пошук**: за ніком — `searchId/{buildSearchIdValueKey('telegram', нік)}/telegram`,
   без ніка — за телефоном (`phone`).
3. **Таблиця на перевірку**: людина → поля → цитати → «знайдено (id) / нова».
   Запис — після підтвердження.
4. **Запис**:
   - знайдено → доповнення `saveOverlayForUserCard({ editorUserId, cardUserId, fields })`;
   - не знайдено → картка-чернетка `reserveProfileCardId()` +
     `saveCreateProfileMutation({ cardId, creatorUid, actorUid, data })`;
   - цитати й `programStatus`, `agencies` → приватна нотатка до картки
     (`multiData/comments/{uid}/{cardId}`).
5. **Звіт**: заведено, доповнено, помилки з причиною.

Запуск коду застосунку з Node: тимчасовий файл у `src/` (не комітити) з
`/** @jest-environment node */`, вхід `signInWithEmailAndPassword` з
`MIGRATION_EMAIL` / `MIGRATION_PASSWORD`:

```bash
NODE_USE_ENV_PROXY=1 CI=true npx react-scripts test \
  --testPathPattern "<файл>" --watchAll=false --forceExit
```
